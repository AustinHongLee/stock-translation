# v3.4.0 更新內容

## 資料不用再從一大坨「歷史不足」開始

- **上櫃近一年歷史改由 GitHub 每日資料樞紐集中補齊。** 官方端一次抓整個上櫃市場，完成日期會記住並接續補，不再讓每位使用者逐檔慢慢等。
- **全新安裝直接使用發行包內的完整資料庫。** 第一次開啟先有上市＋上櫃歷史底，畫面會先開起來；背景只追最新與少數缺口。
- **畫面上的資料包按鈕與 `套用官方資料包.bat` 都會取得 GitHub 最新資料。** 修正過去只重套 zip 內舊 seed、看似完成但缺口沒變的問題。
- **套用後依本機實際資料重算健檢。** 不再沿用資料包內可能過時的「歷史不足」狀態。
- **發版流程會擋下假新資料。** build 固定下載、驗 SHA-256 並檢查最新日期與上櫃深度，不再用開發機舊資料庫打出日期很新的資料包。
- **照顧 v3.0 舊更新器。** App 壓縮檔改名為 `StockTranslator-app-v3.4.0.zip`，避免舊版誤把 `official-data` 當成安裝包而提示缺少 exe／`_internal`。
- 每日資料包仍採安全合併：只補公開市場缺口，不覆蓋自選股、持倉、到價提醒、圖表標註或設定。

## 新增：到價提醒（收盤檢查版）

個股頁多了「到價提醒」按鈕：設定一個價位（到達或高於／到達或低於），**收盤資料更新後**若收盤價到了，首頁晨報和個股頁會顯示「⚑ 已到你設定的價位」。

- 刻意只用每日收盤檢查、不做盤中推播——這個工具的立場一直是不鼓勵盤中盯盤焦慮。
- 每筆提醒只觸發一次，觸發後在首頁保留幾天，之後仍可在個股頁看到紀錄；不需要的提醒可隨時刪除。
- 提醒是你自己的私人資料，存在本機，不會被官方資料包覆蓋。
- 文案中性：只說「已到你設定的價位」，不評好壞、不代表任何買賣建議。

搭配波段關卡使用最順：看到「接近波壓」時，把那個價位設成提醒，之後就不用天天回來盯。
