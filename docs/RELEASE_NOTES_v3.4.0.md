# v3.4.0 更新內容

## 新增：到價提醒（收盤檢查版）

個股頁多了「到價提醒」按鈕：設定一個價位（到達或高於／到達或低於），**收盤資料更新後**若收盤價到了，首頁晨報和個股頁會顯示「⚑ 已到你設定的價位」。

- 刻意只用每日收盤檢查、不做盤中推播——這個工具的立場一直是不鼓勵盤中盯盤焦慮。
- 每筆提醒只觸發一次，觸發後在首頁保留幾天，之後仍可在個股頁看到紀錄；不需要的提醒可隨時刪除。
- 提醒是你自己的私人資料，存在本機，不會被官方資料包覆蓋。
- 文案中性：只說「已到你設定的價位」，不評好壞、不代表任何買賣建議。

搭配波段關卡使用最順：看到「接近波壓」時，把那個價位設成提醒，之後就不用天天回來盯。

*所有功能均為公開資料整理與白話翻譯，不預測股價、不構成投資建議。*
