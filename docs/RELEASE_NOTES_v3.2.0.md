# v3.2.0 更新內容

## 新增：上櫃（TPEx）支援第一版

環球晶、世界先進、群聯這些上櫃股票，現在可以搜尋、同步、看 K 線、體質、估值、營收與財報了——過去輸入上櫃代號會查不到。

具體來說：

- 個股頁：上櫃股票的日線歷史、月營收、財報（一般業）、本益比／殖利率／股價淨值比都會同步，市場欄位顯示 TPEX。
- 全市場資料下載：會同時抓上市＋上櫃清單與最新收盤；上櫃來源暫時故障時只影響上櫃，不會擋住上市流程。
- 每日官方資料包：也會一併累積上櫃的最新收盤與加值資料，幾天沒開程式一樣能補上。
- 資料品質保護：上櫃日線的成交量單位（仟股/仟元）已正確換算成股/元，並有測試鎖住；來源欄位若改版，程式會回報失敗讓你重試，不會靜默寫入錯的數字。

上櫃第一版**尚未包含**（會顯示「資料待補」而不是錯誤）：

- 上櫃股票的股利發放歷史（估價的股利法對上櫃股會顯示資料不足）
- 上櫃三大法人買賣超（來源欄位需實測驗證後，下一版補上）
