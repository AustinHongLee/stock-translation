# v3.1.0 更新內容

> 本次更新涵蓋 v2.0.9 之後累積的所有改進（v3.0.0 未曾單獨發佈，一併包含在內）。
> 發佈時可直接把下面內容貼進 GitHub Release body。

## 打開就看得到的

**首頁新增「自選股今日異動」。** 今日晨報卡現在會告訴你：最近交易日自選股幾漲幾跌、誰變化最大（±2% 以上才列）、外資或三大法人連續 3 天以上在買超／賣超誰、有哪幾檔資料太舊該同步。點異動的股票可直接進個股頁。只整理事實，不預測、不建議買賣。

**ETF 說法更清楚。** 0050、00878 這類 ETF 的估值區，標題改為「配息殖利率區間」，並明確標示不適用個股本益比／股利估價，不再借用個股財報的語氣。

**下載被限流時不再像當機。** TWSE 限流時程式本來就會自動放慢，現在進度列會直接顯示「⚠ 來源限流中，已自動減速 ×N（變慢是保護，不是卡住）」。

**失敗清單變乾淨。** 受益證券／ETN 這類 TWSE 本來就不提供歷史日線的商品，改列在新分類「來源無歷史」，不再佔住「需重試」清單，也不再每次下載白打十幾個空請求；它們的 K 線會靠每日快照自然累積變長。

## 資料更可靠

**補歷史中斷不再白抓。** 回補一年日線時改成每抓完一個月就立刻存檔；中途斷網、關程式或自動暫停，已抓到的月份都保留，下次接著補。

**K 線中間缺洞會自動偵測與修復**（v3.0.0 累積項）。過去「看起來已最新、其實中間缺幾天」的狀況，現在同步時會被抓出來補齊。

**本地資料頁開得更快**（v3.0.0 累積項）。上千檔的資料狀態改用批次計算與快取預熱。

**官方資料包每天自動更新。** 資料包改由 GitHub 每個交易日晚上自動產出，App 開機會自動檢查套用——就算幾天沒開程式，開機後也能一次補上這幾天的收盤與法人資料，不用自己跑全市場下載。

## 其他

- App 更新器不會再把官方資料包誤認成程式安裝包。
- 全市場下載的排序、重試與冷卻機制多項細部修正。
