# v3.3.0 更新內容

## 新增：歷年填息紀錄（存股族久等了）

個股頁的股利區多了一張「歷年填息紀錄」卡，回答存股族最常問的問題：**這檔除息後，過去到底有沒有把價差補回來？**

- 一句白話總結：例如「近 5 年可判定的除息共 6 次，其中 5 次回到除息前價位（填息中位約 23 個交易日）」。
- 逐次列表：每次除息的日期、息值、除息前收盤，以及結果——第幾個交易日回到基準、一年內沒回到、或下次除息前沒回到（季配息會被下一次除息自然截斷）。
- 進行中的除息只顯示「觀察中（目前差 X%）」，不會提前下定論。
- 資料不足（停牌、日線缺洞、除息紀錄太少）會老實說「統計參考性低」，不硬算。

計算全部用你本地已同步的日線與除權息資料，不需要新的網路來源。

一如既往：填息統計只描述過去的價格行為，不代表未來會重演，不預測股價、不構成投資建議。
