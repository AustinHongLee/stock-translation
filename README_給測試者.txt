股票翻譯機 v2.0.3 測試版使用說明

這是 Windows 本機版股票資料整理工具。它會在你的電腦上整理公開資料、畫圖、做白話摘要與本地資料狀態檢查；不會自動下單，也不是投資建議。

一、安裝與第一次開啟
1. 下載 StockTranslator-v2.0.3.zip。
2. 在你習慣的位置建立資料夾，例如：
   C:\Users\你的名稱\Desktop\股票翻譯機
3. 把 zip 完整解壓縮到這個資料夾。
4. 雙擊「股票翻譯機.exe」。
5. 程式會開一個黑色視窗，瀏覽器會自動開啟：
   http://127.0.0.1:8765
6. 使用完畢後，直接關掉黑色視窗即可停止程式。

二、Windows 警告與防毒提醒
- 測試版尚未購買程式碼簽章憑證。
- Windows SmartScreen、Defender 或公司電腦管控可能會對 exe、zip、updater.bat 顯示警告。
- 若看到 SmartScreen，通常要按「其他資訊」再按「仍要執行」。
- 若公司電腦不允許自動換版，請用畫面上的「直接下載」手動更新。
- 如果防毒隔離檔案，請截圖警告內容回報。

三、資料會放在哪裡
- 使用者資料固定放在：
  %LOCALAPPDATA%\StockTranslator\data
- 主要資料庫是：
  %LOCALAPPDATA%\StockTranslator\data\stock_translator.sqlite3
- 程式更新只替換 exe 與 _internal，不會覆蓋 LOCALAPPDATA 內的使用者資料。
- 你的自選股、持倉、圖表標註、指標設定都屬於使用者資料，不會被官方資料包覆蓋。

四、舊版資料與首次匯入
1. 如果你以前用過舊版，舊版 exe 旁可能有 data 資料夾。
2. 第一次開新版時，程式會優先把舊 data 複製到 LOCALAPPDATA。
3. 如果新版已經開過、後來才把舊 data 放回來，畫面可能會跳出「偵測到舊版資料」。
4. 按「匯入」會把舊資料非破壞合併進現在資料庫。
5. 匯入不會刪舊資料，也不會覆蓋現有資料；同一筆資料已存在時會保留現有版本。
6. 按「不要」後，程式會記住選擇，不會一直問。

五、官方資料包
- v2.0.2 起，release 內會附一份官方資料包。
- 它放在程式內部 _internal\seed，不是使用者 data 資料夾。
- 啟動正式版時，程式會在背景檢查官方資料包版本。
- 若資料包比本機已套用版本新，會把「本機缺的公開市場資料」補進資料庫。
- 合併方式是只新增、不覆蓋、不刪除。
- 它不會碰 watchlist、portfolio、chart annotations、indicator prefs 等私人資料。
- 合併前會在 LOCALAPPDATA 的 backups 資料夾留備份，最多保留最近 3 份。
- 如果你的資料比我隨包附的資料少，最簡單方式是雙擊：
  套用官方資料包.bat
- 這個批次檔會無條件重跑隨包資料合併；已存在的資料仍會保留，不會被覆蓋。

六、首頁與個股頁怎麼看
1. 用上方搜尋框輸入股票代號或名稱，例如 2330、台積電。
2. 個股頁最上方會先顯示「先看這家公司」，先看公司做什麼、資料日期與主要提醒。
3. 第一層「30 秒看懂」看盤中報價、消息面、明牌驗證與股利法是否適用。
4. 第二層看體質總評、估值情境、營收與財報。
5. 第三層看 K 線、法人資料、完整資料表與原始資料。
6. 「結構指紋」是進階參考，預設收合。它只描述價格路徑，不收斂消息面，也不預測未來。

七、本地資料頁怎麼用
1. 左側點「本地資料」。
2. 這裡看每檔股票日線筆數、最後資料日、法人資料與波段狀態。
3. 「日線已最新」代表該檔已補到最近完成收盤日。
4. 「日線缺 N 日」代表本機資料少了最近幾個交易日，可以按「補這檔」。
5. 「資料源待補」通常表示公開資料源尚未公布、停牌、冷門股沒有當日資料，或資料源暫時沒回。
6. 「失敗」通常比較像 TWSE 限流、網路中斷或該代號不支援這個端點；等一段時間再試。

八、補這檔與同步
- 個股頁的「同步」和本地資料頁的「補這檔」都會補該檔缺資料。
- 如果只缺一兩天，通常很快。
- 如果資料源當下沒回，畫面會用白話說明可能原因。
- 不需要一直連點；遇到限流時，等 1 到 2 分鐘再試比較好。

九、全市場資料下載
- 左側點「本地資料」可以看到「全市場資料下載」。
- 它負責補本機資料庫的廣度：日線、三大法人、波段關卡狀態。
- 新版會先補最新全市場日線，再跳過已最新股票；不會每次硬重抓一年。
- 第一次建資料庫仍可能花比較久，因為要建立全市場基礎資料。
- 如果已經有官方資料包，本機會先有一份歷史底，全市場下載主要負責追最新與補缺口。
- 畫面上的「失敗」不代表資料壞掉，常見原因是 TWSE 限流、暫時沒回、停牌或資料源尚未公布。
- 如果連續失敗太多，程式會自動暫停，避免一直打資料源。等幾分鐘後可按「繼續」或「重試失敗」。

十、雷達中心
- 雷達中心是全市場篩選與排行榜快照。
- 它和本地資料頁是兩件事：
  - 本地資料頁看資料庫完整度。
  - 雷達中心看篩選結果與目前排行。
- 若覺得雷達結果舊，可以按重新整理雷達快照。
- 若很多股票日線過舊，請先去本地資料頁補資料。

十一、自動更新
1. 程式啟動後會自動檢查 GitHub Releases 是否有新版。
2. 它只連 GitHub 取得版本號、release notes 與下載連結，不上傳任何本地資料。
3. 右上角可以關閉「自動檢查更新」。
4. 有新版時，上方會出現更新通知列。
5. 「下載並更新」會下載 zip、驗證 sha256、等程式關閉後備份舊版、換上新版並重開。
6. 「直接下載」永遠保留。如果自動更新被 Windows 或防毒擋住，請改用直接下載。
7. 手動更新時，請解壓新版 zip 後覆蓋程式資料夾；不要刪 LOCALAPPDATA 裡的 data。

十二、常見問題

Q1. 開不起來，只看到黑色視窗一閃而過？
- 請在程式資料夾空白處按 Shift + 右鍵，開啟 PowerShell，輸入：
  .\股票翻譯機.exe
- 把錯誤訊息截圖回報。

Q2. 瀏覽器沒有自動開？
- 手動打開：
  http://127.0.0.1:8765
- 如果顯示無法連線，請確認黑色視窗還在。

Q3. 顯示 8765 port 被占用？
- 代表可能已經開了一個股票翻譯機。
- 先找舊的黑色視窗關掉，再重開。

Q4. 補資料一直失敗？
- 通常是 TWSE 限流、網路暫時中斷、資料尚未公布、停牌或代號不支援。
- 等 1 到 2 分鐘再試，不要一直連點。

Q5. 資料日期看起來怪？
- 請先確認今天是不是交易日，或最近是否遇到週末、國定假日、颱風休市。
- 若個股資料停在前幾天，可能是資料源尚未公布或該檔近期無資料。

Q6. 更新後資料不見？
- 正常不應該發生。請先不要刪任何資料。
- 到這個位置找資料庫與 backups：
  %LOCALAPPDATA%\StockTranslator\data
- 把畫面截圖與資料夾截圖一起回報。

十三、請幫忙測的重點
- 第一次打開是否順利。
- SmartScreen / Defender 是否阻擋。
- 舊版資料是否能自動接上或跳出匯入提示。
- 本地資料頁的「補這檔」是否能補缺。
- 全市場資料下載是否會跳過已最新股票。
- 個股頁的公司簡介、報價、K 線、法人、估值、報告是否正常。
- 自動更新通知是否清楚，直接下載備援是否看得到。

十四、回報格式
請盡量附：
1. 版本號，例如 v2.0.3。
2. 股票代號，例如 2330。
3. 你點了哪個按鈕或在哪個頁面。
4. 畫面截圖。
5. 你期待看到什麼。
6. 若是資料問題，請說你拿哪個來源對照。
7. 若方便，可附：
   %LOCALAPPDATA%\StockTranslator\data\stock_translator.sqlite3

十五、重要提醒
- 本工具只整理公開資料與本機資料，不代表任何買賣建議。
- 不下單、不預測股價、不保證資料源即時正確。
- 測試版可能有 bug；遇到怪事先截圖，不要急著刪 data。
